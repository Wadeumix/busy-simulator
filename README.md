# busy-simulator

「なんか処理してる風」の作業中ウィンドウを演出するジョークツールです。ビルド/デプロイのログ風テキストが流れ続け、プログレスバーが動き、ごく稀に「異常検知」演出（画面が赤く点滅して揺れる）が発生します。

完全にローカルで動く単一のHTMLファイルです。外部通信は一切行いません。

## できること

- ランダム生成されたビルド/デプロイ風ログが常に流れ続ける
- 1行ごとにプログレスバーが0→100%まで動く（表示時間は1〜20秒の重み付き乱数）
- 最初の5秒間は高速にログが流れる「バースト」演出
- 極めて低確率（0.01%）で20秒の「異常検知」演出（画面が赤く点滅・振動）
- 独立したアプリのようなウィンドウとして起動可能（ブラウザのタブ/アドレスバーなし）

## 使い方

### Electron版（推奨: ブラウザに依存しないネイティブアプリ）

Node.js/npmが入っていれば以下でElectron製の単体アプリとして起動できます（初回のみElectron本体のダウンロードが入ります）。

```bash
npm install
npm start
```

Chromeなどのブラウザに依存せず、`busy-simulator`という独立したアプリとして動作します。将来的にWindows向けのビルドにも対応予定です。

### macOS（Chromeアプリモード）

```bash
./open_busy_window.sh
```

Google Chromeを`--app`モードで起動し、タブやアドレスバーのない独立ウィンドウとして表示します。

### Windows（推奨: Chromeアプリモード）

`open_busy_window.bat` をダブルクリックしてください。Chromeを`--app`モードで起動し、タブやアドレスバーのない独立ウィンドウとして表示します（インストール先を自動検出します）。

### それ以外の方法

`busy_screen.html`をブラウザで直接開いても動作しますが、その場合は通常のブラウザタブとして表示されます。

## カスタマイズ

`busy_screen.html`内の以下を編集することで調整できます。

- `modules` / `actions` / `hosts`: ログ生成に使う単語リスト
- `BUCKETS`: 各表示時間(秒)の出現確率
- `TOTAL_DURATION_MS`: 全体が「完了」するまでの時間（デフォルト2時間）
- `.critical` 関連のCSS/JS: 異常検知演出の見た目
